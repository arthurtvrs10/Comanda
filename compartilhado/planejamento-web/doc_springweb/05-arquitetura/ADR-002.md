# ADR-002 · Transição do C# e autoridade de escrita
Estado: proposta. Reusar C# por uma ponte reduziria reimplementação inicial mas exigiria dois runtimes e uma retirada coordenada. Proposta para equipe pequena: novo monólito modular Spring com catálogo, atendimento, caixa e administração, Next.js para operadores e PostgreSQL por instância de piloto. Conservar o desktop como referência durante ensaio com massa separada. Na virada, pausar lançamentos, reconciliar e entregar escrita a um sistema. Admitir adaptador C# de impressão se o teste físico mostrar necessidade; retirar quando modelos de ticket passarem no adaptador substituto.

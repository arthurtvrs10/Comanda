# Site Comanda

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

Abra http://localhost:3000.

Para produção: `npm run build` e `npm run start`.
Verificações: `npm run lint` e `npm run typecheck`.

Configure o domínio real em `SITE_URL` antes da compilação para publicação.
Termos e privacidade ainda são minutas, aguardando identificação do responsável e e-mail.
O site inclui um marquee de recursos com pausa ao passar o mouse e alternativa para movimento reduzido. A demonstração por abas usa Motion; as imagens são capturas reais do produto. A faixa contínua reinterpreta a referência visual Payer e o padrão Infinite Moving Cards do Aceternity; sua implementação é própria, sem copiar código da biblioteca.

A chamada principal alterna palavras com uma rolagem vertical adaptada do exemplo de kennyotsu no Uiverse. Os links de Instagram (@varthexcompany) e WhatsApp usam o padrão de ícone com ampliação e tooltip de EcheverriaJesus, também disponível por foco no teclado.

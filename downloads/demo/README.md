# Comanda Demonstração 1.4.0

[Baixar instalador Windows x64](https://github.com/arthurtvrs10/Comanda/releases/download/v1.4.0/VarthexComanda-Demo-1.4.0-Setup-win-x64.exe) · [SHA-256](VarthexComanda-Demo-1.4.0-Setup-win-x64.exe.sha256)

Inclui **12 produtos fictícios com fotos e preços de teste**: pastéis, coxinha, kibe, bolinha de queijo, batata frita, refrigerantes e água. As fotos foram geradas por IA e acompanham o pacote para uso offline.

Traz os mesmos recursos da edição normal 1.4.0 atualizada em 22/10/2026: identidade Comanda · por Varthex, abertura de pelo menos 5 segundos, modo escuro, janelas internas, comandas, UN/KG/L, backup com progresso e os dois históricos em Relatórios → Vendas. A conexão Google exige um cliente OAuth configurado separadamente.

Os pacotes da 1.4.0 foram recompilados. Se você baixou a compilação anterior, baixe novamente e use o SHA-256 atual.

Abra pelo atalho **Comanda Demonstração**. Instalação e dados ficam separados da edição normal, em `%LOCALAPPDATA%\VarthexComandaDemo`. O catálogo é criado uma única vez em base vazia; atualizar ou reinstalar preserva os produtos editados. A edição inclui .NET e exige licença offline, usando a ativação do computador. Feche a outra edição antes de abrir.

A 1.4.0 é uma **pré-release**, com instalador sem assinatura de código. Instalação em Windows limpo e OAuth com conta real permanecem pendentes. [Notas da release](https://github.com/arthurtvrs10/Comanda/releases/tag/v1.4.0).

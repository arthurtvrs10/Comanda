# Dados de países e bandeiras

PaisesTelefone.json: recorte de códigos ISO, nomes em português e códigos telefônicos da base https://github.com/mledoze/countries, obtido em 29/10/2026. Derivação disponibilizada sob ODbL 1.0; licença integral em PaisesTelefone-LICENSE.txt. EUA e Canadá usam +1; países com vários prefixos usam o primeiro prefixo cadastrado na base. A lista derivada é distribuída junto ao aplicativo em Assets/PaisesTelefone.json.

Bandeiras PNG: https://flagcdn.com, imagens de bandeiras nacionais para identificação de país. Atribuição: Flagpedia.net / Flagcdn. Arquivos incorporados para funcionamento sem rede.

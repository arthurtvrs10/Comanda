# Comanda · por Varthex 1.4.1 — Demonstração

[![Baixar para Windows](../../docs/design/download-windows.svg)](https://github.com/arthurtvrs10/Comanda/releases/download/v1.4.1/VarthexComanda-Demo-1.4.1-Setup-win-x64.exe) · [SHA-256](VarthexComanda-Demo-1.4.1-Setup-win-x64.exe.sha256)

**Demonstração:** em uma base nova, inclui 12 produtos fictícios com fotos, sem comandas, consumo ou vendas pré-abertos. O catálogo é carregado somente uma vez e não substitui alterações posteriores. Atualizações preservam os dados e a licença existentes.

Atualização de 24/10/2026: servidor local automático, informações da rede e QR Code, logs e fila de eventos do servidor/desktop, configuração de até 500 comandas, adição rápida de UN e personalização de KG/L. Os botões + e … ficam abaixo do preço no cartão; itens prontos no KDS aparecem em verde e riscados. Mantém pagamentos manuais, backup, históricos e janelas internas.

O servidor inicia com o sistema por padrão. Para acessar pelo celular, confira **Configurações → Servidor / acesso pelo celular** e leia o QR Code na mesma rede. Ao parar/reiniciar, use o novo link. O instalador não altera o firewall.

Feche o aplicativo e faça backup antes de atualizar. Instalação por usuário em Windows x64, sem administrador e com runtime .NET incluído. Dados em `%LOCALAPPDATA%\VarthexComandaDemo`, fora do programa; ativação offline obrigatória. O instalador não possui assinatura de código.

O Google Drive exige configurar um cliente OAuth; credenciais não acompanham o instalador. O OneDrive usa pasta sincronizada. As edições têm instalações, atalhos e bases separados.

A 1.4.1 permanece uma **pré-release**. Instalação em Windows limpo, impressão física, rede móvel física e OAuth/envio com conta Google real continuam pendentes. [Notas e limites](../RELEASE-1.4.1.md) · [Release no GitHub](https://github.com/arthurtvrs10/Comanda/releases/tag/v1.4.1).

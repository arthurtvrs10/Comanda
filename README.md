# VComanda

Os projetos estão separados por finalidade:

| Pasta | O que editar aqui |
| --- | --- |
| [windows](windows/README.md) | Aplicativo Windows: código .NET, testes, ferramentas, documentação, demonstrações e instaladores. |
| [site](site/README.md) | Site: páginas Next.js, componentes, imagens e protótipos. |
| [mobile](mobile/) | Aplicativo Android, seus downloads e protótipos. |
| [services](services/) | Serviços de recuperação e transferência de licença. |
| [compartilhado](compartilhado/) | Marca, apresentação, planejamento web, referências e materiais de outros projetos. |
| `artifacts/release-atual` | Publicação oficial preservada no caminho exigido pelo projeto. |

Abra [VComanda.code-workspace](VComanda.code-workspace) no VS Code para trabalhar com Windows e Site em duas áreas. Cada pasta também pode ser aberta individualmente.

A documentação anterior do produto está em [windows/LEIAME-PRODUTO.md](windows/LEIAME-PRODUTO.md). O código não foi alterado nesta etapa de organização.

O registro da organização e as limitações dos caminhos internos estão descritos em [ORGANIZACAO.md](ORGANIZACAO.md).

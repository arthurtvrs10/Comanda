## Edição normal 1.3.0 — sem produtos de teste

[Baixar instalador para Windows x64](https://github.com/arthurtvrs10/VComanda/releases/download/v1.3.0/VarthexComanda-1.3.0-Setup-win-x64.exe) · [SHA-256](VarthexComanda-1.3.0-Setup-win-x64.exe.sha256)

Em uma instalação nova, o catálogo começa vazio, sem produtos de demonstração. Você cadastra os produtos reais do estabelecimento.

Esta versão inclui navegação por abas, catálogo compacto com fotos e edição em modal, prioridade e tempo de comandas, consulta de cozinha e confirmação manual do pagamento. O PIN inicial do atendimento é 1234 em novas instalações; PINs existentes são preservados.

Feche o aplicativo e execute o instalador para atualizar. O runtime .NET está incluído; a instalação é por usuário e mantém os dados e a licença existentes.

O instalador não possui assinatura de código. Esta distribuição está disponível na release v1.3.0 do GitHub e versionada no repositório.

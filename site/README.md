# Site Comanda

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

Abra http://localhost:3000.

Para produção: `npm run build` e `npm run start`.
Verificações: `npm run lint` e `npm run typecheck`.

Configure o domínio real em `SITE_URL` antes da compilação para publicação.
Termos e privacidade ainda são minutas, aguardando identificação do responsável e e-mail.
